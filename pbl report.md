# Interactive Web-Based Fresnel Biprism Interferometer Simulator for Wave Optics Analysis

## Abstract

This project presents an interactive simulator of the Fresnel biprism, an optical device that demonstrates the wave nature of light through interference by division of wavefront. The simulator is written in Python and HTML. Python performs all the physics and draws every figure, and the browser displays the result. The user changes the wavelength, biprism angle, source and screen distances, glass refractive index and the thickness of a thin film, and the simulator recalculates the virtual source separation (d) and the fringe width (β), and redraws the ray diagram, the fringe pattern and the intensity profile. At the default settings (589 nm, α = 0.5°, u = 20 cm, v = 100 cm, μ = 1.5) the model gives d ≈ 1.75 mm and β ≈ 0.405 mm. The simulator confirms that β increases with wavelength and screen distance and decreases as the biprism angle increases.

## 1. Introduction

Interference of light is direct evidence that light behaves as a wave. Two waves can add or cancel depending on the phase difference between them, and for a stable pattern the sources must be coherent. One way to obtain two coherent sources from a single source is to divide a wavefront. Young's double slit does this with two slits. The Fresnel biprism does it by refraction, using two thin prisms joined at their bases.

The biprism is normally studied in a laboratory with a slit, a biprism, a lens and a micrometer eyepiece on an optical bench. Setting it up and changing parameters is slow, and the very small distances involved are hard to visualise. A simulator lets a student change one parameter at a time and see its effect immediately.

## 2. Objectives

1. To demonstrate wavefront division: to show how a single monochromatic source splits into two coherent virtual sources S₁ and S₂ through a biprism.
2. To calculate the virtual source separation using d = 2u(μ − 1)α.
3. To evaluate the fringe width β = λD/d for different wavelengths (λ), refracting angles (α) and screen positions (u, v), and to display the corresponding fringe pattern.

## 3. Theory

### 3.1 The Fresnel biprism

A Fresnel biprism consists of two thin prisms of very small refracting angle (about 0.5° to 1°) joined base to base. A narrow monochromatic slit source S is placed at a distance u in front of the biprism. Each half of the biprism bends the light towards the axis, so the light appears to come from two virtual images of the slit, S₁ and S₂, separated by a small distance d. The two refracted beams overlap in the region behind the biprism, and a screen placed at a distance v from the biprism shows alternating bright and dark fringes.

### 3.2 Division of wavefront and coherence

The biprism splits the single wavefront from S into two overlapping wavefronts by refraction. Because S₁ and S₂ are both images of the same slit, they keep a constant phase difference, which makes them coherent sources.

### 3.3 Condition for interference

At a point P on the screen the two waves superimpose.

- Constructive interference (bright fringe) occurs when the path difference is Δx = nλ, where n = 0, 1, 2, …
- Destructive interference (dark fringe) occurs when the path difference is Δx = (2n + 1)λ/2.

### 3.4 Key equations

| Quantity | Formula | Meaning |
| --- | --- | --- |
| Virtual source separation | d = 2u(μ − 1)α | u = slit to biprism distance, μ = refractive index of glass, α = refracting angle in radians |
| Total distance | D = u + v | Distance from the slit to the screen |
| Fringe width | β = λD / d | Distance between two consecutive bright or dark fringes |
| Intensity | I = I₀ cos²(πx / β) | Intensity at position x on the screen |
| Fringe shift by a thin film | N = (n\_f − 1)t / λ | n\_f = film index, t = film thickness |

Substituting d into the fringe width formula gives β = λ(u + v) / (2u(μ − 1)α). This shows directly that β grows with λ and with v, and falls as α grows.

## 4. Design of the simulator

### 4.1 Tools used

- Python (standard library only: math, http.server, urllib.parse) for the calculations and for building the page.
- HTML for the page structure, the input form and the explanatory text.
- SVG graphics, generated by Python, for the ray diagram, the fringes and the intensity curve.

No external libraries need to be installed, and no JavaScript is used.

### 4.2 Architecture

The program runs a small local web server. When the page is opened, the browser sends the current slider values to Python. Python reads them, calculates the results, builds the whole page as text and sends it back. The user presses Update to repeat this with new values.

### 4.3 Inputs

| Input | Range | Default |
| --- | --- | --- |
| Wavelength λ | 380 to 750 nm | 589 nm |
| Biprism angle α | 0.1° to 1.0° | 0.5° |
| Slit to biprism distance u | 10 to 40 cm | 20 cm |
| Biprism to screen distance v | 30 to 150 cm | 100 cm |
| Glass refractive index μ | 1.40 to 1.70 | 1.50 |
| Thin film thickness t | 0 to 5 µm | 0 µm |

The ranges are chosen so that the fringes stay wide enough to draw clearly.

### 4.4 Algorithm

1. Read the slider values and limit each to its allowed range.
2. Convert α from degrees to radians, distances from centimetres to metres and λ from nanometres to metres.
3. Calculate d = 2u(μ − 1)α, D = u + v and β = λD/d.
4. Calculate the fringe shift N = (n\_f − 1)t/λ when a film is present.
5. For each of 600 vertical strips across a 3 mm window of the screen, calculate I = cos²(π(x − shift)/β), then colour the strip with the colour of the chosen wavelength at that brightness.
6. Draw the intensity curve from the same values.
7. Draw the ray diagram with S, S₁, S₂, the biprism, the screen and the overlap region.
8. Draw six fringe strips for 400 to 700 nm for the same setup, so that the effect of wavelength can be compared at a glance.

### 4.5 Output

The page shows d, D and β, the number of fringes in the 3 mm window, the ray diagram, the coloured fringe pattern, the intensity profile, the wavelength comparison, a how-to-use section, a formula sheet and an explanation of the model.

## 5. Results and observations

### 5.1 Default setting

For λ = 589 nm, α = 0.5° (0.00873 rad), u = 20 cm, v = 100 cm and μ = 1.5:

- d = 2 × 0.20 × 0.5 × 0.00873 = 1.745 mm
- D = 120 cm
- β = (589 × 10⁻⁹ × 1.20) / (1.745 × 10⁻³) ≈ 0.405 mm

About 7.4 fringes appear in the 3 mm window.

### 5.2 Effect of wavelength (α = 0.5°, u = 20 cm, v = 100 cm)

| λ (nm) | Colour | β (mm) |
| --- | --- | --- |
| 400 | Violet | 0.275 |
| 450 | Blue | 0.309 |
| 532 | Green | 0.366 |
| 589 | Yellow | 0.405 |
| 632 | Red | 0.435 |
| 700 | Deep red | 0.481 |

β increases steadily from violet to red, because β is proportional to λ.

### 5.3 Effect of biprism angle (λ = 589 nm, u = 20 cm, v = 100 cm)

| α (degrees) | d (mm) | β (mm) |
| --- | --- | --- |
| 0.25 | 0.873 | 0.810 |
| 0.50 | 1.745 | 0.405 |
| 1.00 | 3.491 | 0.203 |

Doubling α doubles d and halves β, which shows that β is inversely proportional to α.

### 5.4 Effect of screen distance (λ = 589 nm, α = 0.5°, u = 20 cm)

| v (cm) | D (cm) | β (mm) |
| --- | --- | --- |
| 50 | 70 | 0.236 |
| 100 | 120 | 0.405 |
| 150 | 170 | 0.574 |

β increases as D increases, because β is proportional to D.

### 5.5 Effect of a thin film (λ = 589 nm, n\_f = 1.38)

| Thickness t (µm) | Shift N (fringes) | Shift of pattern (mm) |
| --- | --- | --- |
| 1 | 0.65 | 0.261 |
| 2 | 1.29 | 0.523 |

A film placed in one beam adds an optical path (n\_f − 1)t and moves the whole pattern sideways, without changing the fringe width. Measuring the shift therefore gives the film thickness.

## 6. Discussion

The results agree with the theory. The fringe width is proportional to the wavelength and to the total distance D, and inversely proportional to the biprism angle (through d). The colour comparison shows that violet light gives the narrowest fringes and red light the widest. When u is increased, both d and D increase, so the net effect on β is smaller and depends on the value of v.

The simulator makes it easy to explore a combination of parameters that would take a long time to set up on an optical bench. It also removes the need to measure very small distances by hand, since d and β are calculated directly.

## 7. Limitations

- The model assumes ideal conditions: a point-like slit, perfectly coherent monochromatic light and fringes of equal brightness across the window.
- Diffraction at the biprism edges, and the slow fall of intensity away from the centre, are not modelled.
- The ray diagram is schematic, and d is exaggerated so that S₁ and S₂ can be seen.
- Because the page is a form, the user must press Update after changing a slider. The display does not update while a slider is being dragged.
- The slider ranges limit the narrowest fringe that can be drawn clearly.

## 

## 8. Conclusion

An interactive simulator of the Fresnel biprism was built using Python and HTML. It calculates the virtual source separation and the fringe width from the user's chosen parameters and displays the ray diagram, the coloured fringe pattern and the intensity profile. The results confirm that the fringe width increases with wavelength and screen distance and decreases with a larger biprism angle, and that a thin film shifts the pattern. The simulator is a useful aid for understanding division of wavefront interference, and it links the principle to thickness measurement and OCT in biotechnology.
